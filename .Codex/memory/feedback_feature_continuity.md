# Prolonger une application existante

What happened : les mockups d'espaces financiers ont été jugés bien dessinés mais déconnectés de l'application par l'humain.
Why it happened : la commande CS historique interdisait de montrer code/screenshots au designer ; la validation s'est faite contre marque et préférences vieillissantes, pas contre l'expérience réellement utilisée.
How to prevent : pour une feature de cette app, faire visiter la vraie application par le designer (mobile puis desktop), capturer les écrans concernés et prendre le rendu observé comme base de continuité. Conserver shell, navigation, hiérarchie et parcours hors changements demandés.
Ne pas assimiler cohérence de marque à fidélité à l'existant.
L'humain a explicitement demandé cette observation live le 2026-10-22 ; cette instruction prime sur l'interdiction historique de cs-create-experience.
La revue indépendante doit comparer les mockups à la vraie app et relever chaque changement hors périmètre.
